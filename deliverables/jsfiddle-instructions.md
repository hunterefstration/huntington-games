HOW TO PLAY HUNTINGTON GAMES IN JSFIDDLE

1. Go to jsfiddle.net.
2. Find the "HTML" panel (top-left box).
3. Copy ALL of the Main Hub loader code (from the Main Hub tab of this doc) and paste it into that HTML panel. Leave the CSS and JavaScript panels empty.
4. Click "Run" (top-left). The games menu appears in the bottom-right "Result" panel. Pick a game and play.

MAKE IT FULLSCREEN (the /show trick)
- After you press Run, look at the address bar. The link looks like:
    https://jsfiddle.net/abcd1234/
- Add  /show  to the end and press Enter:
    https://jsfiddle.net/abcd1234/show
- That opens ONLY the game, filling the whole page. Press F11 for true fullscreen.
- Tip: once a game is open you can also press the "Fullscreen" button at the top of the player.

SAVE IT SO YOU DON'T HAVE TO PASTE EVERY TIME (free account)
1. Click "Sign Up" at the top-right of jsfiddle.net (top-left "Log in / Sign up").
2. Make a free account with your email, or sign up with Google.
3. Once logged in, paste the loader, press Run, then press "Save".
4. Your fiddle now has a permanent link (and its /show link). Bookmark the /show link and it opens the games straight away next time - no pasting.

NOTES
- The loader downloads the newest games automatically, so you never have to update this code.
- Online multiplayer (Frontline, Blocky Shooter) needs an internet connection.
- The games only run from the official Huntington Games pages. Copies posted on other websites will show a "shut down" message.
